### `res completion`
Print a generated shell-completion definition for restsift (and its short
alias `res`) to stdout. Non-mutating: it only prints a file, it never touches
shell configuration or installs anything.

```bash
source <(res completion bash)                                    # this session only
res completion fish > ~/.config/fish/completions/restsift.fish  # persistent, fish
echo 'source <(res completion zsh)' >> ~/.zshrc                  # persistent, zsh
```

### `res task`
Project task discovery wrapper for AI agents.

```bash
res task list             # list every task this project already defines
res task test             # print the command to run this repo's tests
res task verify           # print the recommended "verify" command to run
res task test --json      # {"schema":"ai.task/v1",...,"data":{"command":...}}
res task todos            # checkbox progress table for every .md under cwd
res task todos docs/      # scope the scan to one directory
res task todos PLAN.md    # scan a single file
res task todos --pending  # also list every unchecked item as PATH:LINE: text
res task todos --json     # per-file + totals as an ai.task/v1 envelope
```

### `res all-f-into-one`
all-f-into-one.sh (formerly all_in_one.sh / combine_files.sh)
Recursively collects filenames and contents, writes them to a single output file at project root.
Prunes ignored directories (entire subtrees) and excludes selected files.
Each file block (header + content + footer) is wrapped inside triple backticks.
A pre-existing output file is rotated to a timestamped <name>.bak.<stamp> alongside it and left in place (prune old .bak files yourself).

```bash
res all-f-into-one --help        # see what this does without combining anything
res all-f-into-one --introspect  # print the machine-readable JSON contract
res all-f-into-one --json | jq .files_combined   # confirm how many files were captured
```

_Output:_

```

```

### `res watch-loop`
Re-run a command automatically whenever watched files change (blocks until Ctrl-C).

```bash
res watch-loop "res verify"          # re-run verify whenever files change (Ctrl-C to stop)
res watch-loop "res task test" sh,md # re-run tests only when .sh or .md files change
```
